How It Works (The Math)

We divide 3D space into a grid. We map a position to a cell ID using a simple integer division. This is the fastest way to partition space.

CellIndex = floor(Position / CellSize)
// Converting 3D coordinates to a unique Integer Key
private int GetKey(Vector3 pos) {
    int x = Mathf.FloorToInt(pos.x / _cellSize);
    int y = Mathf.FloorToInt(pos.y / _cellSize);
    int z = Mathf.FloorToInt(pos.z / _cellSize);
    
    // Combine coordinates into one hash key
    unchecked {
        int hash = 17;
        hash = hash * 23 + x;
        hash = hash * 23 + y;
        hash = hash * 23 + z;
        return hash;
    }
}

Zero Allocation: The Non-Allocating Secret

Garbage Collection (GC) spikes kill games. The secret to a Non-Allocating hash is avoiding `new` in your hot loops.

The Trap: Returning a `new List<T>` every query.
The Fix: Fulfilling a list provided by the caller.

// The "Out List" Pattern
public void Query(Vector3 pos, float radius, List<T> results) {
    results.Clear(); // REUSE the memory buffer

Bucket Pooling

Even if we use the "Out List" pattern for queries, we still have internal lists for each grid cell. If we new List<T>() every time an object enters an empty cell, we're still creating garbage.

The Solution: A simple List Pool. When a cell becomes empty, we don't discard the list; we Clear() it and push it into a Stack<List<T>> to be recycled by the next cell.

// Recycling internal memory
private List<T> GetNewList() {
    return _pool.Count > 0 ? _pool.Pop() : new List<T>();
}

private void RecycleList(List<T> list) {
    list.Clear();
    _pool.Push(list);
}

PurrNet Integration

In PurrNet, you can use this to manage Observers. Instead of PurrNet checking every identity for every connection, you use the hash to find only those in range.

public class PurrNetSpatialAoi : NetworkBehaviour {
    private static SpatialHash<NetworkIdentity> _hash = new(10f);

    public override void OnSpawn() {
        _hash.Insert(Identity, transform.position);
    }

    private void Update() {
        if (IsServer) _hash.Update(Identity, transform.position);
    }

    // Server-side logic to determine who sees who
    public void UpdateObservers(NetworkConnection conn, List<NetworkIdentity> results) {
        _hash.QueryRadius(conn.PlayerPosition, 50f, results);
        // conn.SetObservers(results);
    }
}

O(N) vs O(N²)

Instead of 1,000,000 checks for 1,000 objects, we do ~20-50 per object. Framerates stay stable.

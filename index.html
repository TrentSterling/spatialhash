Beyond the Grid

If you’ve ever built a game with hundreds of units, a massive open world, or a multiplayer system, you’ve hit "The Wall." Your collision checks, pathfinding lookups, or network sync logic starts eating your frame budget for breakfast.

"Checking every object against every other object is fine for 10 units. At 1,000 units, you’re doing 1,000,000 checks. Even on modern CPUs, that’s a death sentence."

While many developers jump straight to Quadtrees or BSP Trees, they often overlook the simpler, faster, and more dynamic cousin: the Spatial Hash.

What is it?

Imagine your game world divided into a grid. Instead of a complex tree structure, a Spatial Hash is essentially a Dictionary where the key is a grid cell coordinate.

The Result

This gives us O(1) average-time complexity for everything. Insertion, removal, and finding neighbors all happen in near-constant time.

Why This Implementation?

Most spatial hashes are rigid. Ours is built for modern gamedev.

Truly Generic

SpatialHash<T> doesn't care if you're hashing NetworkEntities, PathfindingNodes, or Room components. It just works.

Non-Allocating

Unity's GC is the enemy. Our query methods use pre-allocated lists to keep your memory profile flat and your frames smooth.

3D Native

Handles Vector3 natively. Perfect for flight sims, vertical dungeons, or complex 3D environments.

5 Ways This Saves Your Project

Battle-tested solutions for common game development bottlenecks.

Network AOI

Perfect for PurrNet, FishNet, or Mirror. Only sync data to players within a specific "bubble." Keep those packets lean.

O(N) Collisions

Standard collision is O(N²). Turn 1,000,000 checks into 1,000. Handle thousands of projectiles without breaking a sweat.

Smart Pathfinding

Instantly find the nearest nav-node. Query only the immediate cell around a click instead of looping the entire graph.

World Streaming

Manage "Chunks" dynamically. Automatically enable/disable chunks based on player proximity.

Quick Start

Copy, paste, optimize.

ExampleUsage.cs 
using SpatialHash;

// 1. Create (Cell size should be ~2x average object size)
var hash = new SpatialHash<Transform>(cellSize: 10f);

// 2. Insert or Update (Fast O(1))
hash.Update(entityTransform, entityTransform.position);

// 3. Query (Non-allocating results)
List<Transform> results = new List<Transform>();
hash.QueryRadius(playerPosition, 20f, results);

foreach(var nearby in results) {
    // High-performance proximity logic here
}

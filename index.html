OPTIMIZATION 101

Stop Checking Every Object. Use a Spatial Hash.

Most developers hit a wall when their game scales. Checking collisions, finding path nodes, or syncing networks at O(N²) is a death sentence. Here's how to fix it with a simple grid.

Explain the Logic View on GitHub

The Grid Strategy

Imagine your world is a giant chessboard. Instead of asking every piece "Are you near me?", you just look at the square you're standing on (and maybe the 8 around it).

A Spatial Hash maps 3D coordinates to a simple integer key. It's just a Dictionary lookup: Dictionary<int, List<T>>.

  • O(1) Insertion: Math.Floor(pos / cellSize)
  • O(1) Lookup: Only check the relevant bucket.
  • Generic: Works for Colliders, NetworkIdentity, AI, etc.

Where to use it

Network AOI

Perfect for FishNet, Mirror, or Mikkel's PurrNet. Only sync data to players within a specific radius. Don't send movement packets to someone 2km away.

Bullet Hell

Checking 10,000 bullets against 500 enemies? A spatial hash turns that from a slideshow into a smooth 60fps experience.

World Streaming

Use the hash to manage chunks. "Which chunk am I in?" becomes a single integer division.

        // Dictionary maps cell ID -> List of Objects
        private Dictionary> _grid;
        private float _cellSize;

        public SpatialHash(float cellSize) {
            _cellSize = cellSize;

        }

        // Fast, allocation-free key generation
        private int GetKey(Vector3 pos) {
            int x = Mathf.FloorToInt(pos.x / _cellSize);
            int y = Mathf.FloorToInt(pos.y / _cellSize);
            int z = Mathf.FloorToInt(pos.z / _cellSize);
            
            // Simple hash combine
            unchecked {
                int hash = 17;
                hash = hash * 23 + x;
                hash = hash * 23 + y;
                hash = hash * 23 + z;
                return hash;
            }
        }
